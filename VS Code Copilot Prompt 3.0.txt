Task:
Develop a Python web application (with an index page and user interface) that enables users from the United States Forest Service to submit queries related to Federal Financial Assistance (Federal Grants). The application should provide summarized, authoritative responses based on regulatory rules and the full grants lifecycle (pre-award, post-award, closeout).

Functional Requirements
Core Functions:
* Summarize user queries
* Analyze facts and circumstances
* Provide feedback
* Assess risk and oversight
Topic:
Federal Financial Assistance (Federal Grants) — United States Forest Service
User Input Requirements:
1. Circumstances prompting research/monitoring (e.g., Indirect Cost, Matching Funds, Cost Principles, etc.)
2. Optional background information: 
o CFDA (Catalog of Federal Domestic Assistance)
o Recipient Type (State agency | Tribal government | Local government | Nonprofit | IHE | Other)

Response Structure
* Case Summary & Applicable Authorities:
Summarize the case and cite relevant authorities.
* Compliance Checks:
Reference 2 CFR Part 200 with section-level citations.
* Additional References:
Use other authoritative sources as needed.
* Key Requirements:
Highlight requirements, effective dates, and impacts on Federal Financial Assistance.

Behavior:
* Use web search as needed, verifying links are official.
* Validate effective dates; prefer latest codifications.

Output Requirements
* Detailed Summary:
Summarize language found in citations used.
* Explanatory Details:
Include recipient type, grant instrument type, statutory authority, cost principles, and summary of statutory authority.
* Formatting:
Use clear headings, bullets, numbered steps, if/then scenarios, concise checklists as appropriate.
* User Guidance:
After initial response, suggest additional information and output options.

User Interface Requirements
* Theme: 
o Black background
o Light grey boxes with black text
o Boxes have beveled silver border (1.5px width)
* Chat Box: 
o User can write and submit queries
o Submission button included
